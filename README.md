# QuestCraft Mod

QuestCraft is a Minecraft mod designed for the Fabric mod loader, which allows players to remove clothing items using high-value items like diamonds, emeralds, and gold. This mod is inspired by the Jenny mod for Meta Quest 3, providing a unique and immersive experience within the game.

## Install

1. Ensure you have Minecraft version 1.20.1 installed.
2. Install the Fabric mod loader for Minecraft 1.20.1.
3. Download the QuestCraft mod from the GitHub repository or the EnderDevelopment marketplace.
4. Place the downloaded mod file into the `mods` folder in your Minecraft directory.
5. Launch Minecraft using the Fabric profile.

## Use

1. Obtain the diamond, emerald, or gold remover items by crafting them or finding them in chests.
2. Right-click on the clothing item you wish to remove.
3. The clothing item will be removed, and parts of the female human anatomy will be displayed.
